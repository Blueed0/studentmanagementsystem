# AI-Use Statement

**Project:** 01. Student Management System  
**Authors:** Yigit Ali Engin, Nihat Yaman Celen  
**Course:** Object Oriented Programming (OOP)  
**Assessment:** Midterm Assessment – Case Study (35%)

## Disclosure

Artificial intelligence assistance (Cursor / Composer) was used during the development of this project as a productivity and learning support tool.

## How AI was used

- Clarifying OOP design choices (abstract class vs interface, association via `Enrollment`)
- Drafting and refining C# console UI structure and validation messages
- Generating documentation drafts: README, UML Mermaid diagram, flowcharts, test-case table, and assessment report
- Checking coverage of Case 01 requirements against the implemented code
- Helping convert documentation into Word (`.docx`) submission files

## How AI was not used

- AI was not used as a substitute for understanding the solution
- Final design decisions, business rules, and code structure were reviewed and owned by the group
- Both members are responsible for defending the full system in the oral defense

## Student responsibility

Yigit Ali Engin and Nihat Yaman Celen have reviewed the source code and documentation and can explain:

- class responsibilities and relationships
- encapsulation and validation
- inheritance and polymorphism
- enrollment business rules and rejected operations
- how each test case maps to the implementation
